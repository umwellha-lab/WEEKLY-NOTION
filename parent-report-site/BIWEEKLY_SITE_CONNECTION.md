# 2주 성과표 사이트 연결

기존 `/p/[token]` 화면과 DB의 개인 링크 검증을 유지합니다.
학생 연결이 검증된 뒤 해당 학생의 게시 승인된 성과표만 조회합니다.

## 런타임 설정

- `NOTION_API_TOKEN` (기존 이름) 또는 `NOTION_TOKEN`
- `NOTION_REPORTS_SOURCE_ID`: 새 2주 성과표 DB의 data source ID

실제 ID와 토큰을 소스에 넣지 않습니다. 노션 연결에 해당 DB 읽기 권한이 필요합니다.
기존 학생/개인 링크 DB에 등록된 학생에게 적용됩니다. 전체 학생 등록이나 링크 발급을 자동으로 수행하지 않습니다.

## 동작

- `학생` Relation과 `게시 여부 = true`로 조회하고 응답에서도 같은 조건을 재검증합니다.
- 학생 Relation이 여러 명이거나 잘린 행, 휴지통/보관 행은 제외합니다.
- 페이지네이션 전체 조회 후 최신 기간부터 반환하고 기존 화면은 최신 성과표를 표시합니다.
- 실제 0점과 미기록을 구분합니다. A/B/C/D를 점수로 환산하지 않습니다.
- 교사 의견, 다음 목표, 안내문을 표시합니다. 검수 메모와 원본 Relation은 응답에 포함하지 않습니다.
- 수업 내용은 현재 DB에 없으므로 기존 빈 화면을 유지합니다.
- 조회 시 노션의 상태, 게시 여부, 발행일을 변경하지 않습니다.
- 현재 방식은 승인된 노션 자료의 실시간 조회입니다. 발행 당시 내용의 별도 보관과 GitHub 배포 작업은 이 변경에 포함하지 않습니다.

## 검증

Node 22.13 이상에서 `node --test tests/biweekly-report.test.mjs`.
학생 분리, 게시 필터, 0점/미기록, 내부 메모 제외, 페이지네이션 검증.
실제 연결과 전체 사이트 빌드는 별도 확인이 필요합니다.
